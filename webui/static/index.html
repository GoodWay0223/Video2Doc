如何开启隐私模式？
  1. 按需安装至少一个本地引擎（两条命令任选其一）： python -m pip install funasr torch python -m pip install openai-whisper
  2. 运行环境自检，确认 FunASR 或 Whisper 显示已就绪：python scripts\check_setup.py
  3. 重启 Web 服务，重新打开本弹窗并勾选“隐私模式：仅本机识别”：python webui.py
  4. 选择文件并开始转录；“自动”会按 FunASR → Whisper 尝试，本地引擎都失败时不会回退云端。

注意：只选择 FunASR/Whisper 或只关闭云端内容增强，都不等于开启隐私模式。

数据边界：开启后，Video2Doc 不会把音视频或文稿发送给豆包、TeleSpeechASR 或 SiliconFlow；首次使用本地模型可能联网下载权重。上传文件和结果仍保存在本机 output/<任务 ID>/，目前需手动清理。

仅对视频文件生效；音频文件只输出文字稿。

⚙️ 设置

至少配置一个云端 Key 即可识别无字幕视频；有平台字幕的链接无需 Key。Key 只保存在本机 ~/.video2doc/config.json，只会发送给对应服务商；同名环境变量优先生效。

识别引擎在“链接转文稿 / 本地文件”里选择；“自动”会按下面顺序尝试已就绪的引擎。

    仅在勾选“AI 摘要”时，把最多 4000 字文稿节选发送给该模型。
    越大越准、越慢；turbo 速度与准确度平衡（首次使用会下载模型）。
    中文内容保持 zh；外语视频选对应语言，或 auto 自动识别。
    提高人名、术语的识别准确率（豆包 2.0 热词直传，最多 200 个；Whisper 作为提示词）。单个任务的热词可在转文稿窗口里填写。
    热词仍识别错的固定错误，在导出前统一替换（全部任务生效）。

    只安装发布满 7 天的稳定版；原地替换旧版本，不保留重复副本。Python、Node.js 等系统级软件需要管理员权限，这里只给出升级命令。
